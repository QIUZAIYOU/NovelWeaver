# GraphifyLabs.ai 视觉风格一比一复刻指南

## 一、整体风格定位

**核心关键词**：极客黑客风、终端美学、代码即界面、暗色科技、复古终端

该网站采用**暗色终端风格**（Terminal Aesthetic），将代码编辑器/终端的界面语言直接转化为网页设计语言。整体呈现出一种"开发者工具"的质感，而非传统营销网站。每个区块都像是一个终端窗口或代码片段。

## 二、色彩体系

### 2.1 主色调
| 颜色 | 色值 | 用途 |
|------|------|------|
| 背景色 | `#0a0a0a` 或 `#000000` | 页面全局背景 |
| 主文字 | `#e0e0e0` 或 `#ffffff` | 标题、正文 |
| 次要文字 | `#888888` 或 `#666666` | 注释、辅助信息 |
| 强调色 | `#00ff00`（终端绿） | 成功状态、关键数据、命令提示符 |
| 代码色 | `#00ccff`（青蓝） | 代码片段、命令、链接 |
| 警告色 | `#ffaa00`（琥珀） | 高亮、待办、注意 |
| 错误色 | `#ff4444`（暗红） | 错误提示、删除线 |

### 2.2 色彩使用规则
- **背景**：纯黑或近黑，无渐变，无纹理
- **文字层级**：通过灰度差异（白→浅灰→中灰→深灰）建立信息层级，而非字号大小
- **强调色极度克制**：仅在命令行提示符（`$`）、成功标记（`✓`）、关键数据处使用绿色
- **代码片段**：使用等宽字体，青蓝色，背景略深于页面背景（如 `#111111`）

## 三、字体系统

### 3.1 字体栈
```css
/* 主字体 - 等宽字体为核心 */
font-family: 'JetBrains Mono', 'Fira Code', 'SF Mono', 'Consolas', 'Monaco', monospace;

/* 备选无衬线（极少数场景） */
font-family: 'Inter', 'SF Pro Display', -apple-system, sans-serif;
```

### 3.2 字号层级
| 层级 | 字号 | 字重 | 用途 |
|------|------|------|------|
| 超大标题 | `48px-64px` | 400 | Hero区主标题 |
| 区块标题 | `24px-32px` | 400 | 各模块标题（带 `//` 前缀） |
| 正文 | `14px-16px` | 400 | 段落描述 |
| 代码/命令 | `13px-14px` | 400 | 终端命令、代码示例 |
| 注释/辅助 | `12px-13px` | 400 | 元信息、标签、小字 |
| 微文字 | `11px` | 400 | 统计数字后缀、角标 |

### 3.3 排版特征
- **全站等宽**：几乎所有文字使用等宽字体，强化终端感
- **行高宽松**：`line-height: 1.6-1.8`，给代码阅读感
- **无粗体**：极少使用 `font-weight: 700`，靠颜色和字号区分层级
- **字母间距**：`letter-spacing: -0.02em`（标题），`0`（正文）

## 四、布局系统

### 4.1 页面结构
采用**单列流式布局**，无侧边栏，无复杂网格。每个区块（Section）像独立的终端窗口。

```
[Hero区 - 全宽，居中对齐]
[快速安装区 - 全宽，左对齐，代码风格]
[数据展示区 - 全宽，三列统计]
[核心功能描述 - 全宽，左对齐]
[对比表格 - 全宽，双列对比]
[时间线展示 - 全宽，三步骤]
[代码演示区 - 全宽，可交互编辑器]
[功能矩阵 - 全宽，多列图标+文字]
[安全声明区 - 全宽，居中]
[客户证言 - 全宽，居中引用]
[CTA区 - 全宽，居中]
[Footer - 全宽，极简]
```

### 4.2 间距规则
- **区块间距**：`padding: 80px-120px 0`（垂直方向大留白）
- **内容宽度**：最大宽度 `1200px`，居中，`padding: 0 24px`
- **元素间距**：`margin-bottom: 16px-24px`（紧凑，像代码行间距）
- **无圆角**：所有元素 `border-radius: 0`（终端窗口无圆角）

### 4.3 对齐方式
- **Hero/CTA**：居中对齐
- **内容区块**：左对齐（像终端输出）
- **代码块**：左对齐，带 `$` 或 `//` 前缀
- **对比表格**：双列左对齐，中间对齐分隔

## 五、装饰元素与视觉特征

### 5.1 终端符号系统（核心特征）
全站使用代码注释符号作为装饰前缀，这是最具辨识度的设计语言：

| 符号 | 用途 | 示例 |
|------|------|------|
| `//` | 区块标题前缀 | `// graph.growing` |
| `//` | 描述段落前缀 | `// persistent memory engine` |
| `$` | 命令行提示符 | `$ graphify query _` |
| `✓` | 成功/完成标记 | `✓ copied` |
| `✕` | 失败/不支持标记 | `✕ no cloud` |
| `▸` | 列表项标记 | `▸ 56k+ github.stars` |
| `[]` | 状态标签 | `[ ACCESS GRANTED ]` |
| `0//` | 数据统计前缀 | `0// github.stars` |
| `∞//` | 无限/持续标记 | `∞// incremental.growth` |

### 5.2 代码块样式
```css
.code-block {
  background: #0f0f0f;
  border: 1px solid #222;
  border-left: 3px solid #00ff00; /* 左侧绿色边框 */
  padding: 16px 20px;
  font-family: monospace;
  font-size: 13px;
  line-height: 1.6;
  color: #e0e0e0;
  overflow-x: auto;
}
```

### 5.3 数据展示卡片
- 无边框，无背景色（纯黑背景）
- 数字使用大号等宽字体（`32px-48px`）
- 数字后缀使用微文字（`+180 this week`）
- 数字前缀使用 `0//` 或 `∞//` 格式

### 5.4 进度/状态指示器
- 使用纯文本符号：`▸` 表示进行中，`✓` 表示完成
- 无进度条、无加载动画、无圆形图表
- 所有状态都是文本化的

## 六、交互设计

### 6.1 按钮样式
```css
/* 主按钮 - 类似终端命令 */
.btn-primary {
  background: transparent;
  border: 1px solid #333;
  color: #e0e0e0;
  padding: 8px 16px;
  font-family: monospace;
  font-size: 13px;
  cursor: pointer;
  transition: border-color 0.2s, color 0.2s;
}
.btn-primary:hover {
  border-color: #00ff00;
  color: #00ff00;
}

/* 安装命令按钮 - 代码块样式 */
.btn-install {
  background: #111;
  border: 1px solid #333;
  padding: 12px 20px;
  font-family: monospace;
  color: #00ccff;
}
```

### 6.2 链接样式
- 默认：无下划线，颜色 `#888`
- Hover：颜色变为 `#00ff00` 或 `#00ccff`，无下划线
- 无过渡动画或极短过渡（`0.2s`）

### 6.3 输入框
```css
.input-terminal {
  background: #0a0a0a;
  border: 1px solid #333;
  border-bottom: 2px solid #00ff00; /* 底部绿色光标线 */
  color: #e0e0e0;
  font-family: monospace;
  padding: 8px 12px;
  outline: none;
}
```

### 6.4 动画与过渡
- **极简动画**：几乎无动画，或仅有极淡的淡入（`opacity 0→1`）
- **无悬浮效果**：无卡片上浮、无阴影加深
- **光标闪烁**：输入区域可有终端光标闪烁效果（`caret-color: #00ff00`）
- **打字机效果**：Hero区标题可有逐字显示效果（可选）

## 七、各区块详细拆解

### 7.1 Hero区（首屏）
- **布局**：全屏高度，垂直居中，水平居中
- **内容结构**：
  ```
  [小字标语 - 居中，灰色，带 // 前缀]
  // quick.install

  [安装命令 - 居中，青蓝色，等宽字体]
  uv tool install graphifyy && graphify .

  [成功标记 - 绿色，居中]
  ✓ copied

  [元信息 - 小字，灰色，居中]
  pypi v2.1.0 · MIT · 550k+ installs
  ```
- **背景**：纯黑，无图片，无渐变
- **下方衔接**：直接连接下一个区块，无分隔线

### 7.2 数据统计区（graph.growing）
- **布局**：全宽，内部三列等分
- **内容**：
  ```
  // graph.growing

  1 node                    ∑∇²ψP(H|E)              2,500+ QUEUED
  [大号数字]                [公式符号]                [大号数字+描述]

  [下方三列小字描述]
  persistent memory engine  digital twin of your knowledge  [第三列描述]
  ```
- **特征**：数学公式作为装饰元素，数字使用超大等宽字体

### 7.3 核心功能描述区
- **布局**：全宽，左对齐，最大宽度容器内
- **标题格式**：`// 区块名`（如 `// graphify.query`）
- **正文**：带 `//` 前缀的段落，或普通段落
- **命令示例**：`$ graphify query _`（带下划线光标闪烁）

### 7.4 对比表格区（benchmark.compare）
- **布局**：双列对比，无传统表格边框
- **表头**：`// capability` | `others` | `graphify`
- **行样式**：
  ```
  MEMORY
  find_past_information()    ✓        ✓
  retrieve any past...       ✓        ✓

  [分类标题大写，功能名等宽，标记居中]
  ```
- **分隔**：用空行分隔不同类别（MEMORY, CONTEXT, CODE等）
- **标记**：`✓` 绿色，`✕` 灰色/红色

### 7.5 时间线/步骤区（process.graph）
- **布局**：三列等分，或单列垂直排列
- **编号**：`01`、`02`、`03`（等宽字体，灰色）
- **标题**：加粗感通过颜色而非字重实现
- **描述**：普通段落

### 7.6 代码演示区（live.graph_diff）
- **布局**：双栏，左输入右输出
- **左栏**：可编辑文本区（带 `// paste_your_code` 提示）
- **右栏**：提取结果展示（`// extracted.graph`，`0 nodes · 0 edges`）
- **边框**：`1px solid #222`，背景 `#0f0f0f`

### 7.7 功能矩阵区（capability.map）
- **布局**：多列网格（3-4列）
- **每项**：图标（极简线条）+ 标题 + 描述
- **图标风格**：线条图标，单色（白/灰），无填充

### 7.8 安全/隐私声明区（aegis.protocol）
- **布局**：全宽，内容居中
- **标题**：`## Your graph lives on your machine.`（句子标题，非名词）
- **特性列表**：双列，每项带图标和标题
- **图标**：盾牌、锁、断链等极简图标

### 7.9 客户证言区（trusted.by）
- **布局**：居中，引用卡片
- **引用符号**：使用 `"` 或 `>` 作为装饰
- **署名**：缩写（如 `RA`）+ 公司名 + 状态标签（`in production`）
- **标签**：`[ ACCESS GRANTED ]` 风格的状态标签

### 7.10 CTA/邮箱收集区（access.request）
- **布局**：居中，大标题 + 描述 + 输入框 + 按钮
- **输入框**：终端风格，底部绿色光标线
- **按钮**：`[ ACCESS GRANTED ]` 风格的方括号标签
- **隐私声明**：`no_spam=true | unsubscribe=anytime | card_required=false`（键值对格式）

### 7.11 Footer
- **布局**：极简，可能仅一行或完全省略
- **内容**：版权信息、链接列表
- **风格**：最小字号，灰色

## 八、图标与图形风格

### 8.1 图标风格
- **类型**：极简线条图标（Outline style）
- **颜色**：单色，白色或灰色
- **描边**：`1px-1.5px` 细线
- **无填充**：全部镂空
- **无圆角**：直角或微斜角（终端风格）

### 8.2 图形元素
- **无插画**：无3D图形、无卡通插画、无照片
- **数学符号**：使用 LaTeX 风格公式作为装饰（如 `∑∇²ψP(H|E)`）
- **ASCII艺术**：可使用极简的ASCII风格图形
- **无阴影**：所有元素无阴影、无发光

## 九、响应式适配

### 9.1 断点
- **桌面**：`> 1024px`，完整多列布局
- **平板**：`768px-1024px`，部分双列改为单列
- **手机**：`< 768px`，全部单列，字号微调

### 9.2 移动端调整
- 字号缩小 10-15%
- 多列布局改为垂直堆叠
- 代码块横向滚动
- 保持左对齐为主

## 十二、设计哲学总结

GraphifyLabs.ai 的设计核心可以概括为：

> **"把网页当作终端来设计"**

不是"在网页上模仿终端"，而是**彻底将终端的交互语言、视觉语法、信息层级方式**作为整个网站的设计基础。每一个元素都应该问自己："如果这个网站是一个 CLI 工具的帮助文档，它会怎么呈现？"

### 关键设计原则
1. **文本即 UI**：用文本符号（`//`、`$`、`✓`、`[]`）替代传统 UI 组件
2. **代码即内容**：命令行、代码片段不是装饰，而是核心内容形式
3. **克制即高级**：颜色极少（黑、白、绿、青），元素极少（无阴影、无圆角、无渐变）
4. **等宽即秩序**：等宽字体创造了一种独特的垂直节奏感，所有元素对齐在隐形的网格上
5. **终端即信任**：这种设计语言向开发者传达"这是为开发者做的工具"的潜意识信号
